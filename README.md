# Wedding Invitation V4

GitHub Pages-ready vertical scrolling wedding invitation styled to match the supplied vintage water-lily references.

## Important upload rule
Extract the ZIP first. Upload every file and folder to the ROOT of the repository. The following path must exist exactly:

`assets/backgrounds/water-lilies.jpg`

If the background does not appear, confirm that GitHub shows that exact file and capitalization.

## Edit details
Edit `config.js`, then commit the change.

## Add photos
Upload these files into `assets/images/`:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

## Add music
Upload `wedding-song.mp3` into `assets/music/`.

## GitHub Pages
Settings > Pages > Deploy from a branch > `main` > `/ (root)`.

After replacing old files, use a private/incognito browser tab or append `?v=4` to the site address once to bypass cached CSS.
